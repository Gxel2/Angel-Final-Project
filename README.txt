ANGEL HERNANDEZ — PERSONAL PORTFOLIO
=====================================

FILES
- index.html: website structure and English content
- style.css: responsive navy/electric-blue design
- script.js: mobile navigation, scroll reveal, active navigation

HOW TO PREVIEW
1. Keep all three files in the same folder.
2. Open index.html in a modern browser.
3. An internet connection is needed for Google Fonts and the Nikola Tesla portrait.

HOW TO PUBLISH FOR FREE WITH GITHUB PAGES
1. Create or sign in to a GitHub account.
2. Create a new public repository, for example: angel-portfolio.
3. Upload index.html, style.css, and script.js to the repository root.
4. Open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select the main branch and / (root), then Save.
7. Wait for GitHub Pages to provide the public website URL.

BEFORE SUBMITTING
- Verify your age and academic program wording.
- Confirm your teacher's required date and student-name format.
- Replace or add a personal photograph only if you want to.
- Test the public link in a private/incognito browser window.

This is a static website. It does not collect or store visitor information.
